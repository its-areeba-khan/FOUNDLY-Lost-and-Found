# FOUNDLY – Bringing Lost Things Back to You

An AI-powered Lost & Found web application designed to help people find their lost belongings and reconnect them with their owners.

## Live Demo
https://foundly-fyp.vercel.app

## Key Features
- AI-powered lost and found matching
- Natural Language Processing (NLP)
- Computer Vision
- OCR document recognition
- Email notifications
- English and Urdu interface
- Secure communication

## Technologies
- React
- Next.js
- Node.js
- MongoDB Atlas
- NLP
- Computer Vision
- OCR
